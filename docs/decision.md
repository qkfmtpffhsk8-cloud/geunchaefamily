# 과천 거주 + 청약 시나리오 — 판단 근거 정리 (2026-09-10)

> 질문: "청약이 안 될 거면 과천에 이 보증금·월세를 내며 살 이유가 없다. 그래서 갈 것인가, 말 것인가."
> 이 문서는 그 판단에 필요한 사실·숫자·조건을 한 장에 모은 것. 숫자는 2026-09-10 수집 매물(과천 404건, 영등포 3,665건)과 공개 자료 기준.

## 2. 청약 경로별 가능 여부

| 경로 | 요건 | 현재 상태 | 비고 |
|---|---|---|---|
| 84㎡ 일반공급 | 무주택 3년 + 저축총액 순 | △ 통장 약함 | 물량 크면 경계선, 작으면 탈락 |
| 60㎡ 이하 일반공급 | 위 + 소득·자산 기준 | △ | 자산증식 목표와 충돌 |
| 신혼 특공 | 혼인 7년 내 + 세대 무주택 + 소득 | ✕ | 아내 매도 후 혼인신고 시 가능 |
| 생애최초 특공 | 혼인 또는 자녀 + 세대 무주택 + 통장 600만 + 소득세 5년 | ✕ → △ | 아이 인지 시 혼인 없이도 가능성. 추첨이라 통장 무관 |
| 신생아 특공 | 2년 내 출생 자녀 + 세대 무주택 + 소득 | ✕ → △ | 위와 동일 조건 |
| 신혼희망타운 | 신혼/예비 + 세대 무주택 + 소득·자산 | ✕ | 수익공유 모기지로 차익 축소 |

핵심: **아내 1주택을 유지하는 한 열리는 문은 "본인 단독 일반공급" 하나. 아이 출생 시 "생애최초·신생아 특공"이 추가로 열릴 가능성.**

## 6. 결정 규칙 (제안)

**지금(2026-11) 결정**
- 과천 이사 = YES, 단 조건: 전입 가능한 오피스텔·주택·구축 소형 아파트로, 영등포 대비 월 차액 50만 이내.
- 이유: 옵션 비용이 거의 없고, 물량이 확정될 때까지 청약 자격(거주기간·통장)을 쌓을 수 있음.
- 동시에: 통장 25만원 즉시, 다른 3기신도시(하남 교산·남양주 왕숙) 수도권 자격으로 병행 청약.

**2028-06 체크포인트**
- 과천과천지구 일반공급 과천 배정분이 **1,000세대 이상**으로 보이면 → 유지.
- **500세대 미만**이거나 분양이 2031 이후로 밀리면 → 과천 잔류 이유 소멸. 재계약 시점에 영등포로 이동.

**아내 집·혼인 관련 별도 결정 (정보 필요)**
- 아내 집 위치·가격·상승 여력 vs 과천 특공 기대값 비교 → B안(매도+혼인신고+특공) 여부.
- 아이 출생 시: 인지 후 본인 세대 편입으로 생애최초·신생아 특공 자격 되는지 청약홈·주민센터 확인.

## 8. 한 줄 요약

**과천에 갈 이유는 "청약 옵션을 거의 공짜로 사는 것"이고, 그 조건은 아파트가 아니라 오피스텔·주택급에 사는 것이다. 아파트에 살 거면 영등포가 낫다. 2028년 중반 물량이 나오면 그때 계속 갈지 정한다.**
